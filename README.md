# Dependency Graph Visualizer for Rust

Инструмент на Go для анализа и визуализации графа зависимостей пакетов Rust (Cargo.toml), разработанный поэтапно.

## Структура

- **`stages-1-2-3`**: CLI, конфигурация, сбор зависимостей, построение графа, фильтрация, циклы.
- **`stages-4-5`**: Визуализация (Mermaid, ASCII-дерево).
- **`main`**: Полная реализация (слияние `stages-1-2-3` и `stages-4-5`).

## Использование

Настройте `config.csv` и запустите: `go run main.go config.csv`
